
# PathScorer: Dynamic Programming Alignment for Protein Folding Trajectories

PathScorer is a specialized trajectory-alignment tool designed to quantify the similarity between protein structure folding trajectories. By utilizing global dynamic programming (DP), PathScorer aligns a ground-truth Molecular Dynamics (MD) trajectory with a predicted folding pathway (e.g., generated by PathFold). 

Instead of relying on raw root-mean-square deviation (RMSD) or rigid linear gap penalties, PathScorer is custom-built to handle the highly variable rates of conformational change characteristic of complete protein folding pathways.

---

## 🚀 Key Innovations

* **Contact Map–Based Score:** Measures similarity via shared active contacts (relaxed definition $C\alpha \le 14$ Å, ignoring trivial contacts $|i - j| \ge 3$). The score is computed by normalizing intersection of contact maps, which is better equipped for the elongated, unfolded regions, compared to RMSD.

* **Structurally Meaningful Gap Penalties:** Permitting up to 50 frames as penalty free to handle unequal sampling rates. Gaps $> 50$ frames use a non-linear penalty scaled by structural **Dice distance** instead of traditional linear penalty models.

* **Trajectory Consistency Heuristics:** Penalizes unrealistic or non-physical trajectory anomalies, including **Fast Transitions** (excessive pacing), **Slow Transitions** (stagnation), and **Reversals** (backtracking on folding progress).

The final trajectory score is derived by combining the normalized dynamic programming alignment score with the kinetic heuristic penalties:

$$Score_{final} = Score_{DP} - (w_{slow} \cdot P_{slow} + w_{fast} \cdot P_{fast} + w_{back} \cdot P_{back})$$

## 💻 Usage & Command-Line Arguments

To run a baseline trajectory alignment with default parameters, execute:

```bash
python3 pathscorer.py --predicted_trajectory_dir sample_inputs/4JOI_D_predicted_frames/ --native_trajectory_file sample_inputs/4JOI_D_gt_frames.pdb --experiment_name example
```

### Configurable Arguments

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `--predicted_trajectory_dir` | `str` | *Required* | Directory path to the predicted trajectory PDB files. |
| `--native_trajectory_file` | `str` | *Required* | File path to the ground-truth Molecular Dynamics trajectory PDB file. |
| `--experiment_name` | `str` | *Required* | Experiment name or identifier for logging purposes. |
| `--gap_open` | `float` | `-0.0` | Initial penalty applied when opening a gap. |
| `--penalty_after` | `int` | `50` | Maximum continuous frame gap allowed before penalties apply. |
| `--cm_thresh_val` | `float` | `14.0` | Cutoff distance (Å) between $C\alpha$ atoms to register a contact. |
| `--thresh_fast` | `float` | `0.2` | Threshold above which a frame transition is flagged as too fast. |
| `--thresh_slow` | `float` | `0.01` | Threshold below which a frame transition is flagged as too slow. |
| `--penalty_fast_weight` | `float` | `1.0` | Scaling weight applied to the fast transition penalty ($w_{fast}$). |
| `--penalty_slow_weight` | `float` | `5.0` | Scaling weight applied to the slow transition penalty ($w_{slow}$). |
| `--penalty_back_weight` | `float` | `10.0` | Scaling weight applied to folding reversal penalties ($w_{back}$). |
| `--save_pdb_trajectories` | `flag` | `False` | Enable this flag to output superimposed PDB models via PyMOL. |

---

## 📊 Outputs

When execution completes, PathScorer generates:

1. **Alignment Scores (`.tsv`):** A log file inside `/alignment_scores` showing the step-by-step frame mappings, their calculated contact similarities, individual penalty breakdowns, and the final normalized trajectory score.
2. **Visualizable PDBs (`.pdb`):** If `--save_pdb_trajectories` is enabled, the tool builds a PDB file containing structurally aligned frames of both trajectories, ready for side-by-side analysis in PyMOL or Chimera.
